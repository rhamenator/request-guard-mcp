# Support

Community support for Request Guard MCP is provided on a best-effort basis through GitHub issues.

## Before Asking for Help

1. Read the [README](README.md) and relevant files in [`docs/`](docs/).
2. Confirm the problem still occurs on the latest supported release or default branch.
3. Search existing issues and pull requests.
4. Reduce the problem to a minimal, reproducible example.
5. Remove tokens, credentials, personal data, private request content, and sensitive infrastructure details.

Use the [question or support issue form](https://github.com/rhamenator/request-guard-mcp/issues/new/choose) and include the version, operating system, deployment method, MCP client, enabled features or integrations, sanitized configuration, expected behavior, actual behavior, and relevant logs.

## Scope

Maintainers can help with reproducible problems in this repository, documented configuration, and supported deployment examples. Response times are not guaranteed. General Rust support, custom architecture design, incident response, and debugging unrelated infrastructure may be outside project support.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and report privately. Do not include vulnerability details in a public support request.
