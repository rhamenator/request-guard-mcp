# v0.1.5 public artifact qualification

This records bounded checks against the **published** experimental v0.1.5
artifacts. The server classifies inbound request metadata supplied by an MCP
client. It does not intercept traffic or enforce agent egress.

## Public binary and client checks

The extracted public Linux glibc and musl binaries each passed:

```text
python3 scripts/stdio_release_smoke.py --binary <extracted-binary> --expected-version 0.1.5
PASS packaged stdio: initialize, tools, notification, bounded errors, recovery, injection data, secret redaction
```

The glibc binary also passed `scripts/inspector_smoke.py --expected-version
0.1.5 <extracted-binary>` using MCP Inspector 2.5.0: unauthenticated HTTP
rejection, initialize, 23 advertised tools, `classify`, and `explain`.
The official Python MCP SDK 2.3.0 passed
`scripts/python_sdk_stdio_smoke.py --binary <extracted-binary>
--expected-version 0.1.5`: initialize, tool listing, `classify`, and
`explain`. Logs appeared on stderr; the stdio protocol remained on stdout.

The bounded stdio smoke checks malformed and oversized input recovery, a
prompt-like user-agent supplied as classification data, and absence of a
synthetic authentication marker from stdout/stderr. It does not prove
resistance to arbitrary prompt injection, every MCP client, or unbounded
exhaustion. The private five-platform packaged candidate and its limitations
are documented in [v0.1.5 candidate evidence](v0.1.5-stdio-candidate.md).

## npm and skill state

`scripts/package_npm.py` assembled `request-guard-mcp@0.1.5` from these
exact public archives. `npm pack` contained the GPL license, launcher,
README, and five expected binaries, with no runtime npm dependencies. Its
tarball SHA256 was
`24d9354ada9fd2de566da3577176caf979c5755d05ac582f9dd410217389d044`.
A clean local tarball installation passed Inspector 2.5.0 over HTTP and the
bounded stdio smoke. **npm registry publication was pending owner CLI
authentication at the time of this record**; a local tarball test does not
establish that the registry package is live.

The companion Agensi skill ZIP is prepared separately and kept off GitHub.
Its instructions explain the separate server installation, local stdio trust,
and the conditional npm availability. The owner controls the marketplace
listing.

This is evidence for the experimental release, not completion of the
[stable v1.0 gate](https://github.com/rhamenator/request-guard-mcp/issues/125).
