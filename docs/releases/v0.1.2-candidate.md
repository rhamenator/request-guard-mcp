# v0.1.2 experimental release candidate (draft)

This candidate incorporates the post-v0.1.1 transport, classifier, and
adversarial-test fixes. It is not a production-readiness declaration. Keep this
note marked draft until the exact v0.1.2 assets are verified and published.

The release gate includes:

1. Independent Claude Code and Codex review of the release commit, with findings
   resolved or explicitly documented.
2. CI candidate artifacts for Linux x64, Windows x64, macOS Intel, and macOS
   Apple Silicon. Verify all checksums and each platform's bundled binary with
   the release workflow's MCP Inspector smoke.
3. Fresh extraction and installation of the Linux x64 candidate, followed by
   authenticated MCP initialization, tool listing, `classify`, and `explain`.
4. Bounded Kali-to-Ubuntu adversarial retest of the packaged candidate for
   authentication, malformed protocol, classifier evasion, resource limits,
   optional backend failure/recovery, and sensitive-log leakage. Record exact
   binary digest, commands, request counts, resource use, and limitations.
5. Once native assets are published, build npm from those exact assets, install
   it with an empty cache, and rerun the MCP client smoke. Publish npm 0.1.2
   only after that verification and any account approval.
6. Build the Agensi skill ZIP locally from the verified release. Keep it out of
   the GitHub repository and release assets.

Alpine host support is tracked separately in issue #54 for the subsequent
release. The current Linux native and npm binaries require glibc; container
users can use the published image after its manifest and runtime are checked.
