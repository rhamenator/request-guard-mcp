# Claude Code stdio client check against public v0.1.5

On 2026-10-21, Claude Code 2.1.301 connected as a real MCP client to the
checksum-verified **public** Linux x64 glibc v0.1.5 executable. The executable
SHA256 was `2c68a15272619d9b2240303815f4dcf61bc283eac3d022deb3227ea17711e25f`.
This was a process-local stdio connection, not HTTP or the custom WebSocket
transport. No authentication token or optional backend was configured.

An ephemeral MCP configuration had only this server:

```json
{"mcpServers":{"request-guard-lab":{"type":"stdio","command":"/path/to/verified/request-guard-mcp","args":["--stdio"]}}}
```

With that file substituted for `LAB_MCP_CONFIG`, the bounded client command
was:

```bash
claude -p 'Call request-guard-lab classify on synthetic metadata {"ip":"203.0.113.7","method":"GET","path":"/health","user_agent":"Mozilla/5.0"}. Return the verdict.' \
  --mcp-config "$LAB_MCP_CONFIG" --strict-mcp-config \
  --allowedTools 'mcp__request-guard-lab__classify' \
  --output-format stream-json --verbose --max-budget-usd 0.20 \
  --no-session-persistence
```

The local trace showed Claude Code discovering
`mcp__request-guard-lab__classify`, invoking it once with the four synthetic
fields above, and receiving a successful tool result. The server returned
`{"verdict":"allow","score":0,"confidence":"very_low","threat_category":"none","signals":[]}`
along with version, latency, and request ID fields. The final client reply
reported the `allow` verdict. The run exited successfully and reported a
client cost of about US$0.045. The raw trace was kept outside Git; it contains
only synthetic test data but may include client session metadata. Its 12,296
bytes had SHA256
`f482054ebe08c6306b3bd5b193365123a548b1750563949d1a0b84de12d56361`.
The trace contained one `ToolSearch` for `mcp__request-guard-lab__classify`
and exactly one subsequent `tool_use` named
`mcp__request-guard-lab__classify` with the four fields in the command. The
associated `tool_result` had no error and contained the verdict fields above.
The client-side trace did not expose the initialization handshake or
negotiated `protocolVersion`; that protocol detail is not established by this
client run.

This proves one Claude Code stdio tool invocation against the public binary.
It does not establish HTTP compatibility with Claude Code, all tool schemas,
other host platforms, arbitrary prompts, or security against compromised
local processes. Stdio trusts the launching user and has no bearer token;
PostgreSQL remains unavailable in this mode. See the broader
[public artifact qualification](v0.1.5-public-qualification.md) and
[stable-release gate](https://github.com/rhamenator/request-guard-mcp/issues/125).
