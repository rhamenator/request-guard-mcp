# Request Guard MCP v0.1.1-rc.1 pre-release

This pre-release replaces the unusable standard MCP interface in the v0.1.0
binary. It implements `initialize`, `ping`, `tools/list`, and `tools/call` for
the advertised tool contracts. `classify` and `explain` were exercised with
the official MCP Inspector 2.5.0 over authenticated HTTP POST. The companion
skill now requires this version or a newer verified release.

The package includes native bundles for Linux x64, Windows x64, macOS Intel,
and macOS Apple Silicon, with SHA-256 sidecars, plus a separate single-folder
companion skill ZIP. Each platform's bundle must
pass its existing packaged-server smoke test and the pinned Inspector test
before the tag is published. A workflow dispatch can build those candidate
assets privately without creating a GitHub release.

This is a pre-release, not a production-readiness declaration. The stable
release gate still requires broader authenticated client and adversarial
testing, including WebSocket behavior, malformed protocol messages, resource
exhaustion, classifier evasion, backend failure, and independent human review.
The server does not intercept unrelated agent traffic, and does not offer
stdio, SSE GET streaming, OAuth discovery, resources, prompts, or the
2026-07-28 discovery lifecycle. Optional Redis, PostgreSQL, and MaxMind tools
need those services or data; core `classify` and `explain` do not.

Do not reuse the old Agensi skill ZIP. Build the new ZIP from this tag with
`python3 scripts/package_skill.py`, inspect its single `request-guard-mcp/SKILL.md`
entry, and verify it against the tagged binary and intended client before
submitting it to a directory.
