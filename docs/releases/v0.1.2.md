# Request Guard MCP v0.1.2 (experimental)

This experimental release supersedes v0.1.1. It includes the HTTP/WebSocket
protocol and size-limit fixes, stronger encoded-path and scanner signals,
caller-isolated PostgreSQL replay state, and bounded adversarial regression
probes. It remains an **inbound request classifier**: a website or client must
send observations to it and enforce its own decisions. It does not intercept
all agent traffic or provide outbound egress control.

## Install

Download the archive for Linux x64 (glibc), Windows x64, macOS Intel, or macOS
Apple Silicon from this release, verify its matching `.sha256` file, extract
it, and follow the included `INSTALL.md`. Configure a unique bearer token of
at least 32 characters. The core `classify` and `explain` tools work without
Redis, PostgreSQL, or MaxMind data; other tools describe their prerequisites
in `model_info`.

The verified GHCR image is `ghcr.io/rhamenator/request-guard-mcp:0.1.2` for
Linux amd64 and arm64. The separate
[`request-guard-mcp@0.1.2` npm package](https://www.npmjs.com/package/request-guard-mcp/v/0.1.2)
has passed a fresh registry install and MCP Inspector smoke test.

## Verification and limits

The private v0.1.2 candidate passed native bundle/Inspector checks on all
four release platforms and a bounded Kali-to-Ubuntu packaged-binary test. Its
exact binary and archive hashes, protocol and backend results, scanner counts,
resource observations, and review limits are in
[`v0.1.2-candidate-evidence.md`](v0.1.2-candidate-evidence.md). The final
release assets were rebuilt from this tag and independently checked
against their sidecars after publication, as recorded in
[`v0.1.2-final-artifacts.md`](v0.1.2-final-artifacts.md). The companion Agensi skill ZIP is
kept local and is not a GitHub release asset.

This 0.x release remains experimental. The adversarial run does not prove
unlimited denial-of-service resistance, every classifier evasion, a stalled
backend, or compatibility with every MCP client. Alpine/musl native support is
tracked in issue #54 for a subsequent release.
