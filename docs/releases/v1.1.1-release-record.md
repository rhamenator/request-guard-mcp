# v1.1.1 release record

Stable release published 2026-11-26 from `main` commit `466abc13d545923e7ac6bc09c10f6f890f20dd4d`
(annotated tag `v1.1.1`, GitHub release marked Latest). The binary reports `1.1.1`. Written after
the tag because the private qualification binds to the exact source commit.

## What changed since v1.1.0

Dependency and toolchain maintenance only; no scoring or protocol change.

- sqlx 0.8 to 0.9 (#375); the minimum supported Rust version is now 1.94 (#381), and the required
  CI check is the version-free `MSRV`.
- OpenTelemetry crates moved together to 0.33 (#377); config 0.15 (#379); maxminddb 0.33 (#380,
  behavior identical to 0.28 on the MaxMind test databases); thiserror 2 (#376, #378);
  tower-http 0.7 (#170, #373); validator 0.21 (#172); url and cookie security updates
  (RUSTSEC-2026-0592, RUSTSEC-2026-0594, #370); tungstenite held at the version axum uses (#372).

## Independent review

**No independent human review took place.** The owner delegated the release decision to an AI
model (Claude), which performed the self-review recorded here. An LLM review is not a human
review ([release policy](../release-policy-2026-10-27.md)). The owner approved the protected
`stable-release` environment for the tag runs.

## npm 1.1.0 gap

The public npm 1.1.0 package (published 2026-11-24, after the v1.1.0 record said npm was not
published) lacks `vendor/linux-x64-musl` and its launcher says musl is unsupported, although the
v1.1.0 source builds and packages musl. It was not built by `scripts/package_npm.py` from the tagged
archives. It has been deprecated on the registry in favor of 1.1.1.
