# Private v1.0.0-rc.7 npm installation gate

This is a local installation test of a **private, unpublished** release
candidate. It does not qualify a public npm package or authorize a stable tag.
The candidate came from draft PR #149 commit
`74eff98f48c491500a367022477f627c7b74cb7d`, which changes only the
Cargo package and lockfile version from main `1a519538` to `1.0.0`.
[Release workflow 39763985296](https://github.com/rhamenator/request-guard-mcp/actions/runs/39763985296)
passed its five native platform jobs and deliberately skipped stable approval
and public release creation. [Exact-head PR #149 checks](https://github.com/rhamenator/request-guard-mcp/pull/149/checks),
including Rust CodeQL, passed. `git diff 1a519538 74eff98 --stat` shows only
Cargo.toml and Cargo.lock. This run supersedes the earlier private rc.6
candidate for subsequent package tests.

Using the repository's `scripts/package_npm.py` at the same candidate commit,
the verified archives produced a dependency-free `request-guard-mcp@1.0.0-rc.7`
package. `npm pack --dry-run --json` listed exactly the license, README,
launcher, package manifest, and five native binaries. The private tarball
`request-guard-mcp-1.0.0-rc.7.tgz` has SHA256
`d666536a9d52a4fef513406d61594687cddc454ced65db545942a3e9b55a17ff`.
Its installed manifest has no runtime dependencies or install scripts.
The local test did not check npm package-name ownership or publish any npm
provenance or attestation.

The tarball was installed into a new local npm prefix with `--ignore-scripts`
and `--no-audit`. The **installed launcher**, not an extracted binary, passed
`scripts/stdio_release_smoke.py --expected-version 1.0.0`: initialize, tools,
notification, bounded errors, recovery, prompt-like input as data, and absence
of a synthetic secret in protocol output. The same launcher passed the pinned
Inspector 2.11.0 smoke: missing bearer rejected, protocol `2025-06-18`
initialize, 23 tool contracts, and `classify`/`explain` calls. The package
unit tests passed. These tests used synthetic metadata and credentials on
Ubuntu 26.04.1 x64, glibc 2.43, Node 22.20.0 and npm 11.19.1. Inspector
installation used the pinned fixture lockfile and needs Node 22.19.0 or
newer plus network access or a populated npm cache.

To repeat this local gate, use a disposable checkout of candidate commit
`74eff98f48c491500a367022477f627c7b74cb7d`. Download each of the five
named artifacts from the private workflow into one directory with
`gh run download 39763985296 -n request-guard-mcp-<platform> -D
<download-directory>` (substitute each platform listed above). GitHub access
to the private workflow is required and Actions artifacts expire. Then run:

```sh
cd <download-directory>
sha256sum -c *.sha256
python3 <repo>/scripts/package_npm.py --name request-guard-mcp \
  --version v1.0.0-rc.7 --assets "$PWD" --output <new-package-directory>
cd <new-package-directory>
npm pack --dry-run --json
npm pack --pack-destination <private-output-directory>
npm install --prefix <empty-install-directory> --ignore-scripts --no-audit \
  <private-output-directory>/request-guard-mcp-1.0.0-rc.7.tgz
python3 <repo>/scripts/stdio_release_smoke.py \
  --binary <empty-install-directory>/node_modules/.bin/request-guard-mcp \
  --expected-version 1.0.0
python3 <repo>/scripts/inspector_smoke.py --expected-version 1.0.0 \
  <empty-install-directory>/node_modules/.bin/request-guard-mcp
```

This verifies one Linux x64 glibc installation path. The package contains
five platform binaries, but Windows, macOS and musl launcher selection were
not independently installed in this run. The five archive sidecars detect
download corruption, not independent provenance. A final approved tag still
needs its own native, container, npm registry, companion skill, client and
adversarial checks. The Agensi ZIP remains local; no npm candidate or stable
release was published.
